# Observe macOS Processes

A Raycast extension for seeing what’s running on your Mac. It groups related processes by app, adds plain-language labels to common background tasks, and totals CPU and memory use so busy apps are easier to spot.

## What you can do

- Search processes by app name, worker label, or PID.
- Filter by browser, developer tools, system services, or high CPU use.
- Sort apps by CPU, memory, process count, or name.
- See which child process is using the most resources and open a full worker list.
- Open supported browsers’ process or task manager views.
- Send a termination signal to one worker or all processes in an app bundle.
- Open Activity Monitor or copy process details for troubleshooting.

## Shortcuts

| Action | Shortcut |
|---|---|
| Open browser task manager | `Enter` |
| View child workers | `Cmd+Enter` |
| Terminate the busiest worker | `Cmd+Shift+K` |
| Terminate the app bundle | `Cmd+Opt+K` |
| Open Activity Monitor | `Cmd+Shift+A` |
| Copy diagnostic summary | `Cmd+C` |
| Copy app bundle path | `Cmd+Opt+C` |
| Refresh process list | `Cmd+R` |
| Show or hide details | `Cmd+D` |
